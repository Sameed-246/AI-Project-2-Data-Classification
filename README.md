# AI Project 2 – Data Classification Using AI

## Iris Flower Classification Using Decision Tree

This project demonstrates a basic Artificial Intelligence and supervised machine learning classification system using the Iris flower dataset.

## Project Objective

The objective of this project is to build a classification model that can classify Iris flowers into different species based on their measurements.

## Dataset

The Iris dataset contains:

- 150 flower samples
- 4 input features
- 3 classification classes

### Input Features

1. Sepal Length
2. Sepal Width
3. Petal Length
4. Petal Width

### Classification Classes

- Setosa
- Versicolor
- Virginica

## Machine Learning Algorithm

A **Decision Tree Classifier** is used for classification.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn

## Methodology

1. Load the Iris dataset.
2. Convert the dataset into a Pandas DataFrame.
3. Understand and inspect the dataset.
4. Separate input features and target values.
5. Split the dataset into training and testing sets.
6. Train the Decision Tree Classifier.
7. Make predictions on the test data.
8. Calculate model accuracy.
9. Generate a confusion matrix.
10. Visualize the decision tree.
11. Generate an Iris feature graph.
12. Predict the class of a new flower.

## Training and Testing

The dataset was divided into:

- **80% Training Data**
- **20% Testing Data**

The model was trained using the training data and evaluated using the testing data.

## Model Performance

The Decision Tree model achieved:

**Accuracy: 100%**

on the test data used in this project.

## Project Outputs

### Confusion Matrix

The project generates a confusion matrix to evaluate the classification results.

### Decision Tree

The trained Decision Tree model is visualized to show the classification process.

### Iris Feature Graph

A graph using petal length and petal width is generated to visualize the Iris flower data.

## New Flower Prediction

The trained model was also used to predict the class of a new flower.

**Predicted Flower: Setosa**
